# Joyce model card

## Identity

- Model: temporal actor–critic transformer, 77,606 trainable parameters.
- Width 64, two pre-norm transformer blocks, four attention heads, feedforward width 128, GELU, zero dropout.
- Context: up to 16 observations, causal attention and a padding mask; latest valid token supplies policy/value outputs.
- Bundled weights: `artifacts/models/joyce-banana.pt`, selected by banana validation extraction count then mean return. SHA256 and run ID live in `artifacts/data/model-manifest.json`.
- Original code, original artwork, and distributed weights: MIT. This is a small task-specific policy trained from random initialization, not a pretrained language model or an LLM fine-tune.

## Intended use

Local educational demos, controlled RL experiments, checkpoint comparisons, and map editing in Peel's 9×9 museum. CPU inference runs behind the loopback-only Python server. The default bundled model is trained for banana retrieval and extraction; doors and cameras in custom maps are additional challenges outside its training stage.

## Inputs and outputs

The model sees a 5×5, world-aligned local crop with wall/closed-door occlusion. Nine tile categories are embedded. A visibility mask distinguishes unknown from observed floor. Inventory has two bits; direction, previous action, camera direction, and normalized time complete a 56-value encoded observation. Camera direction has an explicit unknown category unless the camera tile is visible.

It receives no global coordinates, full map, teacher map, hidden camera phase, reward, test labels, or simulator `info`. The renderer receives public simulator state independently. One token represents one full local observation; temporal attention does not operate over all tiles separately.

Outputs are five categorical action logits and one value estimate. Evaluation and live demo inference use greedy argmax; training samples actions. Displayed action probabilities are policy confidence, not calibrated probabilities of a successful heist or explanations of reasoning.

## Data and optimization

All data are generated by the local simulator. Behavioral-cloning demonstrations come from a scripted agent with its own observable-history map. Only successful teacher episodes enter the imitation dataset. The teacher remembers more than the student's 16-frame window, so some action labels require information the student may no longer have.

PPO uses fresh trajectories from 16 environments, 64 steps per rollout, four optimization epochs, minibatches of 256, gamma 0.99, GAE lambda 0.95, clipping 0.2, entropy coefficient 0.01, value coefficient 0.5, gradient norm 0.5, and Adam. The refined recipe uses 2,048 teacher episodes, 20 imitation epochs at 3e-4, then 262,144 PPO interactions at 5e-5. Training used a local RTX 3070 Ti Laptop with 8 GB VRAM and PyTorch 2.11.0+cu128.

## Evaluation

The refined champion scored **31/32 (96.9%) validation** and **120/128 (93.75%) test** banana extractions. The test suite was evaluated after checkpoint selection and was not used for further recipe tuning. See [EXPERIMENTS.md](EXPERIMENTS.md) for exact phases, confidence intervals, prior unsuccessful runs, and the harder camera-stage results.

Train/validation/test start rows are disjoint; the test suite is a structured shift in layout. There is only one main training seed per recipe. The result is evidence for this policy on this small domain, not general maze competence or a statistically established advantage of a training algorithm. The separate controlled cue diagnostic does not establish that Joyce's heist performance depends on memory.

## Persistence and compatibility

The observation schema is versioned as `peel-symbolic-5x5-v2-camera-visible-facing`. Loading rejects a mismatched schema. The bundled inference checkpoint contains weights and basic metadata, not optimizer/RNG state. Use full local training checkpoints for resume. Full checkpoints are trusted Python serialization; do not load arbitrary untrusted checkpoint files.

Full resume restores optimizer and RNG state but restarts environments at fresh episode boundaries. It does not restore the exact current simulator/history state. Warm-starting across stages resets optimizer/counters. The current curriculum stops at its bounded budget and does not automatically resume an interrupted multi-stage run.

## Known limitations

Failures include ineffective repeated turns, search loops, forgetting previously seen objects, and unsafe camera timing. Demonstration errors and behavior outside the training distribution can compound. The policy has no persistent memory beyond its window, no online learning in the browser, and no language understanding. Expanding the world or changing reward/observation semantics requires a new experiment and compatible weights.
