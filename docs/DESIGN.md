# Peel design
Visual thesis: a playful midnight museum printed on warm paper, with banana-yellow accents, crisp ink typography, and a little literary thief called Joyce.
Content: masthead and live museum stage; checkpoint/replay controls and mission evidence; measured learning story; build-a-room editor; concise scientific notes.
Interaction thesis: slow ambient camera sweep and a bobbing banana; interpolated character movement with small arrival pulses; responsive tab/inspector changes and focus-visible controls. Respect reduced motion.
Primary agent owns every frontend file and visual. Joyce is a fictional character; literary inspiration does not imply affiliation. All illustration is original vector/canvas work.
